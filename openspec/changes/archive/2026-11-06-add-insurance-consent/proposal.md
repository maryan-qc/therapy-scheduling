# Пропозиція: зріз 3 — статус перевірки страхування й документи згоди клієнта (AC-INS-01…06, AC-DOC-01…11)

## Why

Зараз планувальник перевіряє страхування клієнта поза застосунком, і в картці клієнта не видно, чи прийнято
страхування, чи клієнт платить сам. Документи згоди клієнт підписує теж поза застосунком, і планувальник підтверджує
утримання, не бачачи, чи всі документи підписано. Після цього зрізу планувальник позначає в картці клієнта статус
перевірки страхування, формує англійською документи згоди, бачить, яких підписів ще бракує, позначає документи
підписаними, а коли документи сформовано, підтвердити утримання можна лише тоді, коли всі вони підписані.

## What Changes

Нова можливість `insurance-status`:

- ADDED «Початковий статус страхування» — у кожній картці, зокрема створеній у зрізах 1–2, «Insurance: Not set»
  (AC-INS-01).
- ADDED «Позначення статусу страхування» — планувальник або адміністратор позначає «Verified», «Not accepted» чи
  «Private pay», бачить «Insurance status saved.», статус бачать усі, хто бачить картку (AC-INS-02, AC-INS-03).
- ADDED «Терапевт лише бачить статус» — у картці свого клієнта, без можливості змінити, зокрема напряму в обхід сторінок
  (AC-INS-04, AC-INS-05).
- ADDED «Без входу — лише сторінка входу» для картки зі статусом (AC-INS-06).

Нова можливість `consent-documents`:

- ADDED «Документів ще немає» — «No consent documents yet.» (AC-DOC-01).
- ADDED «Формування документів згоди» — для «Adult» два документи, для «Child» три, кожен «Not signed», рядок «Missing
  signatures: …» (AC-DOC-02, AC-DOC-03).
- ADDED «Текст документа» — англійською, із заголовком, «Client: …», для дитини «Guardian: …», «Prepared: …»
  (AC-DOC-04).
- ADDED «Позначення підпису» — стан «Signed РРРР-ММ-ДД ГГ:ХХ», рядок «Missing signatures: …» або «All consent documents
  signed.» (AC-DOC-05, AC-DOC-06).
- ADDED «Підтвердження утримання лише з підписаними документами» — «Sign all consent documents before confirming.»,
  утримання лишається «Held»; з усіма підписаними — «Confirmed» (AC-DOC-07, AC-DOC-08).
- ADDED «Терапевт лише бачить документи» — у картках своїх клієнтів, без позначення підпису (AC-DOC-09); чужий клієнт —
  «You don't have access to this client.» (AC-DOC-10).
- ADDED «Без входу — лише сторінка входу» для документа (AC-DOC-11).

Можливість `slot-holds` не змінюється: за «Припущеннями» #34 AC зрізу 1 (зокрема AC-HOLD-12, 19, 23, 27, 36) лишаються
як є — якщо документів для клієнта не формували, підтвердження працює як у зрізі 1. Нове правило для клієнта зі
сформованими документами — вимога «Підтвердження утримання лише з підписаними документами» у `consent-documents`.

## Assumptions

Припущення PM (#33):

- Статус — одне з чотирьох значень: «Not set», «Verified», «Not accepted», «Private pay». «Not set» — лише початковий:
  позначити можна «Verified», «Not accepted» або «Private pay» і змінювати між ними будь-коли; повернути «Not set» не
  можна.
- У кожної картки є статус, зокрема в картках зрізів 1–2 — «Not set».
- Статус показано в картці рядком «Insurance: <статус>» — текстом, не лише кольором.
- Терапевт бачить статус лише в картках своїх клієнтів; у розкладі терапевта статус не показано.

Припущення PM (#34):

- Набір документів залежить від типу клієнта: «Adult» — «Consent to treatment» і «Cancellation policy
  acknowledgement»; «Child» — ці два і «Release of information»; у цьому порядку. Тип не змінюється, тож набір теж.
- Картки зрізу 1 (тип «Adult») отримують набір для «Adult».
- Документи належать картці клієнта, а не утриманню: підписані один раз, діють для всіх утримань клієнта.
- Документи формують один раз на картку: після формування сформувати знову не запропоновано, а повторна спроба (зокрема
  двома планувальниками одночасно) не створює другого набору.
- Текст документа — англійською: заголовок, «Client: <ім'я>», для дитини — «Guardian: <ім'я опікуна>», «Prepared:
  <РРРР-ММ-ДД>» і сталий синтетичний текст згоди.
- Стан документа — «Not signed» або «Signed <РРРР-ММ-ДД ГГ:ХХ>»; підпис позначає планувальник або адміністратор.
- «Missing signatures: …» перелічує непідписані через кому в порядку набору; непідписаних немає — «All consent documents
  signed.»; документів не формували — «No consent documents yet.».
- Якщо документи сформовано, підтвердити утримання можна лише з усіма «Signed»; інакше — «Sign all consent documents
  before confirming.», утримання лишається «Held». Документів не формували — підтвердження як у зрізі 1. Решта правил
  підтвердження зрізу 1 перевіряється раніше за документи.
- Терапевт бачить документи й текст лише в картках своїх клієнтів; для чужих — те саме повідомлення, що й для чужої
  картки.
- Час — America/Los_Angeles з точністю до хвилини, формат РРРР-ММ-ДД ГГ:ХХ; мова інтерфейсу — англійська; дані
  синтетичні (`*@example.test`).

Власні припущення (розробник):

- Терапевт, який напряму пробує позначити документ підписаним чи сформувати документи, отримує відмову без змін даних —
  так само, як для статусу страхування (AC-INS-05) і за матрицею прав.
- «Prepared» і «Signed» — дата й час у поясі практики в момент дії.
