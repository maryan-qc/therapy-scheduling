# Дельта: consent-documents

## REMOVED Requirements

### Requirement: Документів ще немає

**Reason**: рішення PM 2026-11-06 — вимогу HryhoriiHaponiukQuitCode/therapy-scheduling-spec#34 перенесено зі зрізу 3 на пізніший зріз (roadmap «пізніше»); у продукті документів згоди немає, тож ця поведінка не чинна.

**Migration**: нічого не мігрує — у продукті цієї поведінки немає, утримання підтверджується, як у зрізі 1 (slot-holds). Коли PM поверне #34 у зріз, специфікацію відновлюємо новою зміною `add-consent-documents` з гілки `task/consent-documents` (реалізація збережена там, PR #46 закрито без злиття).
