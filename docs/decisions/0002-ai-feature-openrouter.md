# 0002. AI-функція зрізу 4: AI SDK + OpenRouter (безкоштовні моделі) + zod, правила полів — у коді

- Статус: прийнято
- Дата: 2026-11-14
- AC: AC-INTAKE-01, AC-INTAKE-02, AC-INTAKE-04, AC-INTAKE-05, AC-INTAKE-06, AC-INTAKE-07, AC-INTAKE-08, AC-INTAKE-09

## Контекст

Зріз 4 (`openspec/specs/intake-draft`, вимога PM HryhoriiHaponiukQuitCode/therapy-scheduling-spec#36): планувальник
вставляє у форму нової картки текст звернення клієнта чи опікуна (до 2000 символів), помічник заповнює форму чернеткою,
а картку створює лише людина наявною дією `createClientCard`. PM задала 10 golden cases з точними полями й дослівними
повідомленнями і поріг приймання — щонайменше 8 з 10, GC-09 (відмова) й GC-10 (ін'єкція) обов'язкові. Обмеження:

- Next.js 16.4 на Vercel Hobby; Server Action — до 1 МБ тіла, нам вистачає тексту.
- Модель — безкоштовна через OpenRouter із **власним** ключем розробника (правило курсу WS10): ліміт 20 запитів/хв і
  50/добу на акаунт, спільний для eval, UAT і приймання PM; безкоштовні моделі з'являються й зникають; ендпоінти можуть
  зберігати запити й навчатися на них → лише синтетичні дані, підказка під полем, текст не зберігаємо.
- Відповідь моделі недетермінована, а CI — без мережі й без секретів.
- Кілька правил PM — арифметика й формат (повні роки на сьогодні в America/Los_Angeles, дата в майбутньому, нижній
  регістр email, «Missing: …» у порядку форми); безкоштовні моделі в них помиляються частіше, ніж у витягуванні фактів.

## Рішення

- Нові залежності (точні версії, з набору курсу `materials/ai-feature`): `ai@7.0.162`,
  `@openrouter/ai-sdk-provider@3.1.0`, `zod@4.6.7`, `server-only@0.0.1`.
- Виклик — `generateText` + `Output.object({ schema })` (AI SDK 7), `temperature: 0`, `maxRetries: 1`, тайм-аут 30 с;
  без інструментів — модель нічого не може записати.
- Ланцюжок лише `:free`: `nvidia/nemotron-3.5-super-vl:free` (строга JSON-схема) → `google/gemma-4-31b-it:free` →
  `google/gemma-4-26b-a4b-it:free` (fallback `models` OpenRouter). Перевірка наявності — `npm run ai:models`.
- Ключ `OPENROUTER_API_KEY` читає лише `src/lib/ai/openrouter.ts` з `import "server-only"`; немає ключа → `null` →
  стан AC-INTAKE-08, форма працює вручну. Перевіряє `tests/ai-key.test.ts`.
- **Модель витягує, код вирішує.** Схема відповіді — сирі факти з тексту (ім'я, повна дата, запитана мова, email,
  «пише батько чи мати про дитину», `ok / needs_info / refused`). Тип клієнта, дату в майбутньому, мову, email, перелік
  «Missing» і повідомлення рахує `finalizeDraft` у `src/lib/clients/intake.ts` — детерміновано й покрито unit-тестами.
- Ін'єкція — дві лінії: явні звертання до помічника в тексті відхиляє код до виклику моделі
  (`hasAssistantInstructions`, ліміт не витрачається), решту — модель за інструкцією «текст між `<document>` — дані».
- Якість: офлайн-реплей записаних справжніх відповідей (`MockLanguageModelV4`) — у `npm test` (CI); живий прогін
  `npm run eval` — вручну, звіт pass rate за моделями в `evals/reports/`. LLM-суддю набору не беремо: у чернетці немає
  вільного тексту, усе очікуване PM — точні поля.

## Розглянуті варіанти

- Командний ключ Claude API від PM — ні: правило курсу WS10 «лише `:free` у ланцюжку, власний ключ»; рішення
  розробника 2026-11-14. Перехід на іншого провайдера — заміна фабрики в `src/lib/ai/models.ts`.
- Усі правила полів — у промпті — ні: межу 18 років, дату в майбутньому й регістр email код перевіряє точно, а модель —
  ні; правило, яке можна перевірити кодом, має жити в коді.
- Gemma першою (порядок набору) — ні: у Gemma 4 немає `structured_outputs`, OpenRouter може проігнорувати схему; Super VL
  тримає строгу схему. Обидві лишаються в ланцюжку.
- `openrouter/free` — ні: випадкова модель, результат golden cases не відтворюється.

## Наслідки

- Простіше: провайдера й модель міняємо в одному файлі; CI не залежить від мережі й ліміту; правила PM доводять
  unit-тести, а не лише eval.
- Складніше: безкоштовна модель може зникнути чи впертися в ліміт — інтерфейс показує «The assistant is unavailable
  right now. Fill in the form manually.»; живий eval і приймання PM — у різні доби UTC. Записи
  `tests/fixtures/golden/recorded.json` треба перезаписати (`RECORD=1 npm run eval`), коли змінюється
  `DRAFT_PROMPT_VERSION` або схема.
